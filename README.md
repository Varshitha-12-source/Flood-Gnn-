#  FloodGraph - Flood Risk Prediction

An end-to-end flood risk prediction system that uses a **Graph Convolutional Network (GCN)** to predict district-level flood risk and presents the results through an interactive **Streamlit dashboard**.

## Overview

Flood events are influenced by multiple geographic, environmental, and historical factors. FloodGraph models relationships between districts as a graph and uses a Graph Convolutional Network to learn patterns associated with flood risk.

The system includes:

- Historical flood data processing
- District-level feature engineering
- Graph construction
- Graph Convolutional Network (GCN)
- Flood-risk prediction
- Risk-level classification
- Interactive Streamlit dashboard
- Flood prediction output generation
